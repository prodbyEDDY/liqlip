# Liqlip — продуктовая спека

> Что строим и как это должно ощущаться. Технический дизайн — [ARCHITECTURE.md](ARCHITECTURE.md),
> статус и волны — [ROADMAP.md](ROADMAP.md). Версия спеки: v1.1, 2026-11-26 (v1 — 2026-11-25;
> v1.1 добавляет скриншоты, §9). Решения Eddy, на которых она стоит, — ROADMAP §11.

## 0. Продукт одним абзацем

**Liqlip** — менеджер буфера обмена для Windows, вынесенный из Liquid Tools в отдельное
приложение и проработанный до глубины Raycast Clipboard History / Paste. Всё, что пользователь
копирует (текст, ссылки, код, цвета, контакты, картинки, файлы), сохраняется локально и
мгновенно доступно по `Alt + V`: шелф с карточками, поиск с фильтрами, папки, избранное,
сниппеты, очередь вставки, OCR по картинкам. С v1.1 — ещё **скриншоты** класса CleanShot /
ShareX (§9): `PrtSc` → область или окно → аннотации прямо на экране → Enter; снимки живут в той же
ленте. Никакой диктовки и studio. Внешний вид шелфа — тот же «жидкий» монохромный, что в Liquid
Tools; внутри — клавиатура-first, надёжная вставка, приватность по умолчанию.

**Принципы:**
1. **Hotkey → набрал → Enter.** Самый частый сценарий (вставить недавнее) — за секунду, без мыши.
2. **Ничего не теряется и ничего лишнего не сохраняется.** Ни одно копирование не пропущено;
   пароли из менеджеров паролей не сохраняются никогда.
3. **Вставка всегда попадает туда, откуда вызвали.** Если не может — честно говорит почему.
4. **Выглядит как Liquid Tools.** Монохром, squircle, карточки, пилюли — один в один.
5. **Привычно.** Настройки — обычное окно с разделами; горячие клавиши — как у Windows/Raycast.

Не цели v1: синхронизация между устройствами, шифрование БД (v2), авторасширение сниппетов по
ключевому слову (v2), AI-функции, мобильные клиенты.

## 1. Поверхности

| Поверхность | Что это |
|---|---|
| **Шелф** (`picker`) | Главное окно: поиск + пилюли + сетка карточек + строка подсказок. Вызывается хоткеем, треем, или наведением на край (опция). Перекрывает экран, не в Alt+Tab, не на панели задач |
| **Просмотр** (Quick Look) | Слой внутри шелфа: крупное превью записи + информационная таблица; редактирование текста |
| **Меню действий** | Слой внутри шелфа: поисковый список всех действий над выбранным (Ctrl+K, ПКМ, кнопка ⋯) |
| **Очередь вставки** | Поповер внутри шелфа + глобальный хоткей «вставить следующее» |
| **Настройки** (`settings`) | Классическое окно Windows с системным заголовком: слева разделы, справа группы настроек. Здесь же онбординг при первом запуске |
| **HUD** (`hud`) | Крошечный неактивируемый тост у курсора, когда шелф уже скрыт: «Скопировано — нажмите `Ctrl+V`», «Очередь пуста», «Запись на паузе» |
| **Трей** | Иконка + меню: открыть, пауза, пропустить следующее, удалить недавнее, снимки экрана, настройки, выход |
| **Оверлей захвата** (`capture`, v1.1) | Замороженный экран: выбор окна/области, лупа, рамка с ручками, редактор аннотаций прямо на экране (§9.2–9.3) |
| **Миниатюры после снимка** (`shots`, v1.1) | Стопка миниатюр в углу экрана: копировать, редактировать, закрепить, сохранить, перетащить (§9.4) |
| **Окно редактора** (`editor`, v1.1) | Обычное окно: правка снимка или картинки из истории с живыми аннотациями (§9.5) |
| **Закреплённые картинки** (`pin-*`, v1.1) | Безрамочные окна поверх всех с картинкой (§9.5) |

## 2. Захват (что и как сохраняется)

### 2.1. Типы записей

| Тип (`kind`) | Как распознаётся | Карточка |
|---|---|---|
| `text` | всё текстовое, не попавшее ниже | текст до 7 строк |
| `link` | одна строка-URL (http/https/ftp/file, `www.`) | иконка ссылки + хост; полный URL в просмотре |
| `code` | эвристика (отступы, токены, плотность пунктуации; ≥2 признака) | моноширинный текст |
| `color` | целая строка `#rgb/#rrggbb/#rrggbbaa` (обязателен `#`), `rgb()/rgba()/hsl()/hsla()`; 6 цифр без `#` и без букв a–f — **не** цвет (защита от одноразовых кодов) | заливка цветом + HEX-чип |
| `contact` | целая строка — email или телефон (7–15 цифр, `+` или разделители) | иконка почты/телефона + значение |
| `image` | растровое изображение в буфере (PNG / DIBV5 / DIB) | превью целиком, без обрезки |
| `file` | список файлов/папок из Проводника (CF_HDROP) | иконка семейства формата + имя; «+N» для нескольких |
| `screenshot` (v1.1) | снимок экрана Liqlip (не из буфера — из захвата, §9.6) | как `image` + значок камеры |

Пилюли: **Все · Текст** (text + contact) **· Ссылки · Картинки** (image + screenshot) **· Скриншоты ·
Файлы · Код · Цвета · Избранное · Сниппеты**, затем папки пользователя. У каждой — счётчик.

### 2.2. Сохраняемые форматы

Для каждой записи хранится основной вид **и** доступные богатые форматы, чтобы «Вставить как…»
мог выбрать: plain text, HTML (`HTML Format`, вместе с `SourceURL`, если есть), RTF, PNG,
список файлов (+ `Preferred DropEffect`). Виртуальные файлы (`FileGroupDescriptor`) и прочие
форматы в v1 не сохраняются.

### 2.3. Правила

- **Ничего не пропускать:** изменение буфера ловится системным уведомлением
  (`AddClipboardFormatListener`), а не опросом; занятый буфер — ретраи с бэкоффом.
- **Дедупликация глобальная** по хэшу содержимого: повторное копирование уже существующей
  записи **поднимает её наверх** (обновляет время), а не создаёт дубль. Счётчик копирований растёт.
- **Источник** — приложение-владелец буфера (`GetClipboardOwner` → процесс → exe), с запасным
  вариантом «активное окно». Имя и иконка приложения сохраняются один раз на приложение.
- **Лимиты:** картинка > 64 МП — не сохраняется (запись в лог); текст > 2 МБ — сохраняется
  усечённым до 2 МБ с пометкой «усечено» в просмотре; > 2 000 файлов в одном копировании —
  сохраняются первые 2 000 путей.
- **Свои записи не ловим:** когда Liqlip сам кладёт данные в буфер (вставка, копирование),
  это не создаёт новую запись.

### 2.4. Приватность (по умолчанию включено всё)

1. **Системные маркеры приватности Windows** — запись не сохраняется, если в буфере есть
   любой из: `ExcludeClipboardContentFromMonitorProcessing`; `CanIncludeInClipboardHistory` = 0;
   `CanUploadToCloudClipboard` = 0; `Clipboard Viewer Ignore`. Это закрывает KeePass, KeePassXC,
   Bitwarden (ставит только два последних DWORD), Windows-диалоги и т. п.
2. **Игнорируемые приложения** — список exe; выбор из запущенных приложений с иконками или
   через «Обзор…». Предзаполнен: KeePass, KeePassXC, 1Password, Bitwarden.
3. **Похоже на секрет** (тумблер, по умолчанию вкл.): не сохранять текст, целиком являющийся
   номером карты (проверка Луна) или ключом API по известным префиксам (`sk-`, `ghp_`, `gho_`,
   `github_pat_`, `xox[bap]-`, `AKIA…`, `AIza…`, `-----BEGIN … PRIVATE KEY-----`).
4. **Пауза записи:** 5 мин / 30 мин / 1 ч / до возобновления — из трея, хоткея и шелфа.
   Во время паузы шелф показывает плашку «Запись на паузе · Продолжить».
5. **Пропустить следующее копирование** — из трея и хоткея (одноразово).
6. **Удалить недавнее:** за последние 5 / 15 / 30 мин, 1 ч, 24 ч — из трея и меню действий,
   с подтверждением. Сценарий «случайно скопировал пароль».
7. Всё хранится **только локально**; никакой сети.

## 3. Шелф

### 3.1. Вид (как в Liquid Tools)

Тот же визуальный язык, что шелф Liquid Tools: монохромная панель с тенью `summoned`,
радиус 24, строка поиска 38 px с «невидимым» полем, горизонтально листаемые пилюли 36 px,
регулярная сетка квадратных карточек (превью 1:1 + строка мета 36 px с иконкой приложения,
заголовком и форматом-бейджем). Новое — **строка подсказок** внизу (отключается в настройках):

```
↵ Вставить в Chrome   ⇧↵ Без форматирования   Space Просмотр   Ctrl K Действия      ⏸ · Очередь 3
```

Левая часть называет **реальное целевое приложение** (иконка + имя окна, из которого вызвали).
Если цели нет (рабочий стол, свои окна) — `↵ Копировать`. Если цель запущена от администратора —
`↵ Копировать · окно администратора` (см. 6.3).

**Расположения** (как в Liquid Tools): `center` (по умолчанию, 760×640; вариант «одна строка»
760×360), `left`/`right` (панель 400×826), `top`/`bottom` (полоса 800×360). Монитор: **под
курсором** (по умолчанию) / основной / конкретный. Для краевых расположений — опция «открывать
наведением на край» (строгий триггер Liquid Tools: курсор упёрся в крайний пиксель ~200 мс,
без зажатой кнопки).

### 3.2. Карточка

- Превью по типу (см. 2.1), под ним мета: иконка приложения-источника · заголовок
  (пользовательское имя, если переименована) · бейдж формата (`TXT · URL · CODE · HEX · PNG ·
  PDF · ZIP · EMAIL · TEL …`). Время на карточке **не** показывается (решение Eddy 2026-09-22) —
  оно в просмотре и в подсказке при наведении.
- **Действия по наведению/выбору:** три кнопки поверх низа превью — **Копировать · Избранное ·
  ⋯** (⋯ открывает меню действий). Вне наведения/выбора кнопок нет.
- Избранная — маленький значок ❤ в мета-строке. В папке — без отдельной метки.
- Выбранная клавиатурой — кольцо `focus-visible`; в мультивыборе — отметка ✓ в углу превью.
- При зажатом `Ctrl` на первых девяти видимых карточках появляются цифры `1…9`.

### 3.3. Активация и фокус

- **Вызов хоткеем/треем:** шелф открывается **с клавиатурным фокусом** — можно сразу печатать
  (поиск), ходить стрелками, жать Enter. Целевое окно запоминается до показа шелфа.
- **Вставка:** шелф прячется → фокус возвращается целевому окну → Liqlip ждёт, пока оно реально
  станет активным → отпускает зажатые модификаторы → посылает вставку. Никаких «вставилась
  буква v» и двойных Enter.
- **Открытие наведением на край:** пассивный режим (фокус остаётся в рабочем окне, шелф
  работает мышью); клик в поиск делает шелф клавиатурным.
- **Закрытие:** `Esc` (послойно, см. 3.5) · повтор хоткея · клик вне панели · уход фокуса ·
  успешная вставка/копирование (если «закрывать после копирования» вкл.). Фокус всегда
  возвращается туда, где был.

### 3.4. Поиск

- Печать в любом месте шелфа уходит в поиск. Дебаунс 120 мс. Совпадения подсвечиваются в
  карточках и в просмотре.
- Ищет по **полному** тексту записи, заголовку, URL, именам файлов и (если включён OCR) по
  тексту на картинках. Регистронезависимо, по подстроке, кириллица и латиница одинаково.
- **Токены-фильтры** (с автодополнением во всплывающей подсказке при вводе `:`):
  `app:chrome` · `type:link|text|code|color|contact|image|file|screenshot` (`shot` — синоним) · `in:<папка>` · `is:fav` ·
  `is:snippet` · `date:today|yesterday|week|month` · `-слово` (исключить). Токен становится
  чипом в поле поиска; Backspace на пустом поле удаляет последний чип.
- Пилюля и запрос **сбрасываются** при следующем открытии, если прошло > 60 с (настройка
  «запоминать поиск»: никогда / 60 с / всегда; по умолчанию 60 с).
- Пустой результат: «Ничего не найдено» + кнопки «Очистить поиск» и «Искать во всех типах»
  (если активна не «Все»).

### 3.5. Клавиатура (канонический список)

| Клавиши | Действие |
|---|---|
| печать | поиск |
| `↑ ↓ ← →` | навигация по сетке **в двух измерениях** (вверх/вниз — по рядам; в полосе top/bottom ←→ основные) |
| `Home` / `End` | первая / последняя карточка (при пустом поиске; иначе — каретка в поле) |
| `PgUp` / `PgDn` | на экран вверх / вниз |
| `Enter` | вставить в целевое окно (или копировать, если цели нет) |
| `Shift+Enter` | вставить как обычный текст |
| `Ctrl+Enter` | только копировать (шелф закрывается по настройке) |
| `Alt+Enter` | вставить и **не закрывать** шелф |
| `Ctrl+1…9` | вставить N-ю видимую карточку; `Ctrl+Shift+1…9` — как обычный текст |
| `Space` (при пустом поиске) / `Ctrl+Y` | просмотр (Quick Look) |
| `Ctrl+K` / ПКМ / `⋯` | меню действий |
| `Ctrl+D` | избранное вкл/выкл |
| `F2` | переименовать |
| `Ctrl+E` | редактировать текст (в просмотре) |
| `Ctrl+O` | открыть (ссылку — в браузере, файл — приложением по умолчанию) |
| `Ctrl+Shift+O` | показать в Проводнике |
| `Delete` | удалить (с тостом «Отменить», `Ctrl+Z`) |
| `Ctrl+Z` | отменить последнее удаление / перенос / очистку |
| `Ctrl+A` | выбрать все видимые; `Shift+стрелки` — расширить выбор; `Ctrl+клик` / `Shift+клик` |
| `Ctrl+Shift+S` | добавить выбранное в очередь вставки |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | следующая / предыдущая пилюля; `Alt+1…9` — пилюля N |
| `Ctrl+F` | фокус в поиск |
| `Ctrl+,` | открыть настройки |
| `Esc` | послойно: закрыть меню/просмотр → снять выбор → очистить поиск → закрыть шелф |

Сочетания матчатся по **физическим клавишам** (`KeyboardEvent.code`), чтобы работали в русской
раскладке. Сфокусированная кнопка внутри карточки владеет своим Enter/Space.

### 3.6. Мышь

- **Клик** по карточке — вставить (если «вставлять по клику» вкл. и есть цель), иначе копировать.
- **Двойной клик** — то же, что Enter (на случай, если клик настроен на выбор).
- **ПКМ** — меню действий для карточки (или для выделения, если карточка в нём).
- **Перетаскивание** карточки на пилюлю «Избранное» / папку — пометить / переложить;
  за пределы шелфа — нативный drag-out (файлы, картинки как PNG-файл, текст как текст).
- Колесо в полосе top/bottom листает горизонтально без Shift.

### 3.7. Меню действий

Поисковый список (печать фильтрует), у каждого пункта — сочетание справа. Набор зависит от
типа и от того, одна запись или выделение:

- **Вставить** · Вставить как обычный текст · **Вставить как…** (HTML / RTF / обычный текст /
  PNG / файлы — только доступные форматы) · Вставить и не закрывать
- **Копировать** · Копировать как… · Копировать путь (файлы) · Копировать цвет как HEX / RGB / HSL
- **Открыть** · Открыть с помощью… (файлы) · Показать в Проводнике
- **Преобразовать ▸** (текст; результат можно вставить, скопировать или сохранить как новую
  запись): ВЕРХНИЙ / нижний / Каждое Слово / Как в предложении · Обрезать пробелы ·
  Убрать переносы строк · Убрать пустые строки · Сортировать строки · Убрать дубли строк ·
  JSON: форматировать / сжать · URL: закодировать / декодировать · Base64: закодировать /
  декодировать · HTML → обычный текст · slug
- **Скопировать текст с картинки** (OCR) · **Сохранить как сниппет**
- **Избранное** · **В папку ▸** (список + «Новая папка…» + «Убрать из папки»)
- **Переименовать** · **Редактировать**
- **Добавить в очередь**
- **Ещё из этого приложения** (ставит токен `app:`)
- **Удалить** · **Удалить недавнее ▸**
- Для выделения: Вставить всё (через разделитель: новая строка / пробел / табуляция / ничего —
  запоминается) · Копировать всё · Объединить в новую запись · В избранное · В папку · В очередь ·
  Удалить

### 3.8. Просмотр (Quick Look)

Слой поверх сетки внутри шелфа (шелф не меняет размер). Слева/сверху — крупное превью,
справа/снизу — таблица:

| Поле | Значение |
|---|---|
| Источник | иконка + имя приложения |
| Тип | тип + основной формат |
| Размер | байты / для картинки — пиксели и вес / для файлов — число и суммарный размер |
| Текст | символы · слова · строки |
| Скопировано | дата и время первого копирования; «последний раз …» если копировали снова |
| Использовано | N раз, последний раз … |
| Папка / Избранное | если есть |

- Текст — полностью, с переносами и подсветкой совпадений; переключатель «показывать
  невидимые символы» (пробелы, табы, переносы); код — моноширинно.
- Ссылка — полный URL, кнопка «Открыть»; картинка — вписана целиком, колесо/±/0 — зум;
  файлы — список путей с отметкой «файл не найден»; цвет — большой свотч + HEX/RGB/HSL с
  копированием по клику.
- `←/→` — предыдущая/следующая запись не выходя из просмотра; `Enter` — вставить;
  `Ctrl+E` — редактирование (textarea; Сохранить `Ctrl+S` / Отмена `Esc`): сохраняет текст в ту же
  запись (пересчитывает хэш), формат HTML/RTF при этом сбрасывается.

### 3.9. Папки и избранное

- Избранное — флаг; в пилюле «Избранное» порядок **ручной** (перетаскиванием).
- Лента «Все» — **хронологическая** (последнее скопированное первым), чтобы `Ctrl+1` всегда был
  последним копированием. Настройка «Избранное в начале ленты» — выкл. по умолчанию.
- Папки: создать (кнопка «+» в конце пилюль, меню действий, настройки) · переименовать
  (двойной клик по пилюле / ПКМ) · переупорядочить (перетаскивание пилюль) · удалить
  (с подтверждением: «записи останутся в истории» / «удалить вместе с записями»).
  Запись в одной папке одновременно; «Убрать из папки» есть.
- Избранное, записи в папках и сниппеты **не удаляются ретенцией** и не стираются «Очистить
  историю» (только «Очистить всё» с двойным подтверждением).

### 3.10. Сниппеты

- Сохранённые шаблоны текста: имя, тело, (зарезервировано) ключевое слово.
  Пилюля «Сниппеты» в шелфе, карточка — имя + начало тела.
- Создание: «Сохранить как сниппет» из любой текстовой записи; «Новый сниппет» в меню
  действий пилюли; раздел «Сниппеты» в настройках (список + редактор).
- **Плейсхолдеры** (разворачиваются при вставке): `{clipboard}` — текущий текст буфера;
  `{date}`, `{time}`, `{datetime}` с необязательным `format="yyyy-MM-dd"` и
  `offset="+2d"`; `{weekday}`; `{uuid}`; `{cursor}` — где оказаться каретке после вставки
  (Liqlip нажимает ← нужное число раз). Модификаторы `| uppercase | lowercase | trim`.
  В редакторе — подсказка-справочник и живой предпросмотр развёртки.
- Авторасширение по ключевому слову (печатаешь `;sig` → подставляется) — **v2**.

### 3.11. Очередь вставки (Paste Stack)

- Добавить в очередь: `Ctrl+Shift+S` / меню действий / перетаскивание на индикатор очереди.
- **Режим сбора:** тумблер «Собирать копирования в очередь» — каждое новое копирование
  автоматически дописывается в очередь, пока режим включён.
- Индикатор в строке подсказок «Очередь N»; клик — поповер: упорядоченный список,
  перетаскивание, удалить элемент, «Развернуть порядок», «Очистить».
- **Вставить следующее** — глобальный хоткей (по умолчанию `Alt + Shift + V`) вставляет
  верхний элемент в активное окно без открытия шелфа и снимает его с очереди. Опция «добавлять
  перенос строки после каждой вставки». При пустой очереди хоткей ничего не вставляет и
  показывает HUD «Очередь пуста».
- **Вставить всё** — через выбранный разделитель.
- Очередь живёт в памяти до выхода из приложения.

### 3.12. OCR по картинкам

- Локальный Windows OCR (`Windows.Media.Ocr`), языки — установленные языковые пакеты Windows
  (RU + EN обычно есть). Работает в фоне после сохранения картинки, очередью, не тормозит захват.
- Текст с картинок участвует в поиске; действие «Скопировать текст с картинки»; в просмотре —
  раскрывающийся блок «Распознанный текст».
- Настройка: вкл/выкл (по умолчанию вкл.), язык (авто / конкретный из установленных),
  «Распознать заново всё» (фоново, с прогрессом).

### 3.13. Состояния

- **Загрузка** — скелетон той же геометрии, что сетка (а не полосы).
- **Пусто (первый запуск)** — обучает: «Скопируйте что-нибудь — оно появится здесь. `Alt + V`
  открывает Liqlip из любого окна.» + 3 подсказки по клавишам.
- **Пусто по пилюле** — свой текст для каждой (Избранное: «Нажмите ❤ или `Ctrl+D`…»;
  Сниппеты: «Сохраните текст как сниппет…»; папка: «Перетащите сюда карточки…»).
- **Ошибка загрузки** — понятное сообщение + «Повторить».
- **Новые записи при прокрутке вниз** — плашка «Новые записи · Показать» (только для записей
  из захвата; собственные действия пользователя её не вызывают).
- **Отмена** — тост «Удалено 3 · Отменить» 6 с (`Ctrl+Z` работает, пока тост виден и ещё 30 с).
- **Догрузка страницы** — скелетон-ряд в конце сетки.

## 6. Вставка — гарантии

1. Цель — окно, активное **до** вызова шелфа (если это не окно Liqlip, не трей/меню и не рабочий
   стол).
2. Последовательность: спрятать шелф → вернуть фокус цели → дождаться (до 500 мс), что цель
   активна → отпустить зажатые модификаторы → `Ctrl+V` через `SendInput`. Если фокус не
   вернулся — **ничего не печатаем**, запись остаётся в буфере, и у курсора на ~1.6 с
   появляется HUD-тост «Скопировано — нажмите `Ctrl+V`» (шелф к этому моменту уже скрыт).
3. **Окна администратора (UIPI):** если цель запущена с более высоким уровнем целостности,
   Liqlip не может послать ввод — заранее определяет это, в строке подсказок пишет
   «окно администратора», по Enter копирует и показывает HUD «Скопировано — нажмите `Ctrl+V`».
4. **Особые приложения:** настройка «Сочетание вставки для приложений» (раздел «Шелф»,
   группа «Дополнительно»): по exe — `Ctrl+V` (по умолчанию) / `Shift+Insert` /
   `Ctrl+Shift+V`. Предзаполнение для терминалов (Windows Terminal, conhost, mintty) —
   только после сверки с документацией каждого терминала при реализации.
5. Вставка как обычный текст — кладём только `CF_UNICODETEXT`.
6. После вставки буфер **остаётся** с вставленным содержимым (как у Raycast).

## 7. Нефункциональные требования

| Метрика | Цель |
|---|---|
| Показ шелфа по хоткею | ≤ 120 мс до первого кадра с карточками (окно создано заранее, первая страница из SQLite ≤ 10 мс) |
| Поиск | ≤ 50 мс на 50 000 записей (FTS) |
| Захват | запись в ленте ≤ 300 мс после копирования текста; картинки — превью в фоне |
| Память в простое | ≤ 80 МБ всего процесса (шелф свёрнут, строки освобождены) |
| Холодный старт | ≤ 1.5 с до готовности хоткея |
| Объём | 50 000+ записей без деградации прокрутки (виртуализация) |
| Надёжность | ни одного пропущенного копирования при 10 копированиях/с; зависшее приложение-источник не вешает Liqlip (таймауты чтения) |

Цели по объёму и скорости обеспечиваются построением (индексы, keyset-курсор, FTS, виртуализация) и
проверяются планами запросов и малыми тестами. Стенд на 50 000 записей не делаем (решение Eddy
2026-11-26: без крупных синтетических данных).

- Двуязычность EN + RU, все строки — ключи i18n.
- Светлая и тёмная темы, `prefers-reduced-motion`.
- Доступность: роли `grid`/`gridcell`/`option`, `aria-label` у иконок-кнопок, видимый фокус.
- Логи — локальный файл с ротацией, без содержимого буфера.

## 9. Скриншоты (v1.1, волны W5–W8)

> Решение Eddy 2026-11-26 (ROADMAP §11): в Liqlip добавляется захват экрана и редактор аннотаций
> класса CleanShot / ShareX. Основа — Liquid Tools (нативный захват, выбор окна, лупа, раскладка
> текста), взаимодействие переписано с нуля. **Studio / мокапы — вне рамок.** Технический дизайн —
> ARCHITECTURE §18. Разведка: `docs/prompts/_RESEARCH-W5-SCREENSHOT-SOURCE.md` и
> `_RESEARCH-W5-ANNOTATION-UX.md` (локальные файлы координатора).

### 9.0. Принципы

1. **Хоткей → область → (рисую) → Enter.** Самый частый сценарий «снял и вставил в чат» — две
   секунды, без мыши после выделения.
2. **Инструмент рисования всегда рисует.** Нажатие с активным инструментом начинает новый объект —
   поверх, внутри, рядом с другим. Выделение — только инструментом «Выделение» (`V`) или с зажатым
   `Ctrl`. Новые объекты не обводятся рамкой и ручками.
3. **Ничего не теряется.** Аннотации хранятся редактируемыми: снимок из истории открывается с теми
   же стрелками и текстом, которые можно двигать. `Esc` никогда молча не выбрасывает нарисованное.
4. **Не крадёт фокус.** После снимка фокус возвращается окну, где был пользователь, — `Ctrl+V`
   сразу вставляет снимок. Окно миниатюр после снимка не активируется.
5. **Выглядит как Liqlip.** Монохромный интерфейс; цвет — только в пользовательском содержимом
   (цвета аннотаций и сам снимок).

### 9.1. Способы захвата

| Действие | Хоткей по умолчанию | Ещё откуда |
|---|---|---|
| **Снимок области** (оверлей: окно или область) | `PrtSc` | трей, шелф (меню действий → «Снимок экрана»), `liqlip --capture` |
| **Снимок экрана** (монитор под курсором, без оверлея) | `Ctrl + PrtSc` | трей, `F` в оверлее |
| **Снимок активного окна** (без оверлея) | не задан | трей |
| **Повторить прошлую область** (тот же прямоугольник того же монитора, без оверлея) | не задан | трей, `R` в оверлее |
| **Скопировать текст с экрана** (оверлей → область → OCR → текст в буфер, картинка не сохраняется) | не задан | трей, кнопка «Текст» в оверлее |
| **Снимок с задержкой** 3 / 5 / 10 с | — | трей ▸; обратный отсчёт — HUD у курсора |

- Хоткеи — в разделе «Горячие клавиши» (группа «Скриншоты»), запись нажатием, как у остальных.
- **Windows 11 и `PrtSc`.** Если в Windows включено «Использовать клавишу PrtSc для открытия
  инструмента «Ножницы»» (`HKCU\Control Panel\Keyboard\PrintScreenKeyForSnippingEnabled = 1`), Liqlip
  показывает предупреждение в разделе «Скриншоты» и в онбординге: что происходит, кнопка «Открыть
  параметры Windows» (`ms-settings:easeofaccess-keyboard`) и кнопка «Назначить другое сочетание». Реестр
  за пользователя Liqlip **не меняет**. Ошибка регистрации хоткея всегда видна в настройках (не
  только в логе).
- Повторный `PrtSc`, пока открыт оверлей, игнорируется (никакого сброса работы).

### 9.2. Оверлей захвата

**Заморозка.** Хоткей мгновенно снимает **все мониторы** (до показа любых окон Liqlip); шелф, если
открыт, прячется. Оверлей появляется на мониторе под курсором поверх замороженного кадра с
затемнением ~20 %. Пока выделение не начато, оверлей **следует за курсором** на другой монитор
(кадр того же момента). Область через границу мониторов — вне рамок v1.

**Этап 1 — выбор цели** (как Liquid Tools, ShareX):
- Наведение подсвечивает окно под курсором (DWM-границы; вложенные поверхности — дочерние HWND
  страницы браузера, панели; `Alt` — держать внешнее окно). **Клик** — снять это окно (рамка
  встаёт по окну). **Драг** — область; `Shift` — квадрат; `Alt` — от центра; `Space` (держать) —
  двигать рисуемую область. Клик по рабочему столу — весь монитор.
- **Лупа** у курсора (по умолчанию вкл., `M` — вкл/выкл, колесо — увеличение) с перекрестием и
  координатами; при драге — живой размер `W × H` (настройка «Показывать размеры»).
- Стрелки — сдвиг курсора на 1 px (`Shift` — 10 px), `Enter` — начать/закончить область с клавиатуры.
- `F` — весь монитор; `R` — прошлая область; `Esc` — закрыть оверлей.

**Этап 2 — рамка и инструменты** (по умолчанию; настройка «Снимать сразу при отпускании» пропускает
этот этап и сразу выполняет «Готово»):
- Выбранная область остаётся светлой, вокруг — затемнение. **Ручки рамки** (8) стоят **снаружи**
  границы, чтобы рисование внутри никогда их не задевало. Рамку двигают драгом за полосу вокруг
  границы или за чип размеров; размер — ручками; `Ctrl+стрелки` — двигать рамку на 1 px (`Shift` — 10),
  `Alt+стрелки` — менять размер на 1 px (`Alt+Shift+стрелки` — на 10) от правого/нижнего края
  (`Ctrl+Alt+стрелки` не используются: на части ПК их перехватывает драйвер Intel — поворот экрана).
  Драг вне рамки без активного инструмента — новая область.
- **Панель** пристыкована к рамке: снизу снаружи; если места нет — сверху; если рамка на весь
  экран — внутри у нижнего края. При обычной области панель рамку не перекрывает; когда жест
  рисования проходит под панелью, панель становится полупрозрачной и прозрачной для мыши.
  Состав: инструменты редактора (§9.3) · полоса свойств · действия **Текст** (OCR) · **Закрепить** ·
  **Сохранить как…** · **Копировать** · **Отмена** · **Готово** (основная кнопка).
- `Enter` или двойной клик по области в «Выделении» на пустом месте — **Готово**. `Ctrl+C` — только
  копировать и закрыть; `Ctrl+S` — сохранить в папку и закрыть; `Ctrl+Shift+S` — «Сохранить как…»;
  `Ctrl+P` — закрепить на экране.
- **Esc по шагам:** отменить текущий жест → закончить ввод текста → снять выделение → инструмент
  «Выделение» → закрыть. Если нарисован хоть один объект, последний шаг показывает плашку
  «Закрыть без сохранения? `Esc` — да» и закрывает только по второму `Esc` в течение 3 с.
- Правый клик во время рисования отменяет создаваемый объект; иначе — ничего (никаких удалений).

**Готово** выполняет действия из настроек «После снимка» (§9.7): копирует в буфер, сохраняет файл,
добавляет в историю Liqlip, показывает миниатюру (QAO) или редактор. Оверлей закрывается, фокус
возвращается окну, бывшему активным до хоткея.

### 9.3. Редактор аннотаций

Один и тот же редактор работает в оверлее (этап 2) и в **окне редактора** (правка снимка или любой
картинки из истории, §9.5).

**Инструменты** (клавиша — по физической клавише, работает в русской раскладке):

| Клавиша | Инструмент | Что делает |
|---|---|---|
| `V` | Выделение | клик — выбрать; `Shift+клик` — добавить/убрать; драг по пустому — рамка выбора; драг объекта — двигать |
| `A` | Стрелка | прямая; средняя ручка выделенной стрелки — дуга; стили: прямая · изогнутая · двусторонняя |
| `L` | Линия | `Shift` — шаг 45° |
| `R` | Прямоугольник | контур или заливка (`F`), скругление; `Shift` — квадрат, `Alt` — от центра |
| `E` (`O`) | Эллипс | то же; `Shift` — круг |
| `P` (`D`) | Перо | сглаженный штрих ровной толщины; `Shift` в начале — прямая с шагом 45° |
| `H` | Маркер | широкий полупрозрачный (multiply), плоские концы, под фигурами; `Shift` — горизонталь |
| `T` | Текст | клик — текст с автошириной; драг — блок с переносом; стили: обычный · плашка (текст на цветном фоне) |
| `N` | Счётчик | клик — кружок со следующим номером; удаление перенумеровывает; цифра на выделенном счётчике задаёт его номер |
| `B` | Скрыть | сплошная плашка (по умолчанию) · пиксели · размытие (`Shift+B` — следующий вариант); считается от исходных пикселей, неотличимо в экспорте |
| `S` | Прожектор | затемняет всё вне выбранных областей |
| `C` | Обрезка | только в окне редактора (в оверлее обрезка = рамка); неразрушающая: `Enter` — применить, `Esc` — отменить, повторно `C` — вернуть исходные границы |
| `I` | Пипетка | берёт цвет со снимка в текущий цвет |

Ещё: вставка картинки `Ctrl+V` (PNG/JPEG из буфера → объект «картинка», двигается и
масштабируется с сохранением пропорций).

**Правила взаимодействия** (каждое — проверяемое, ARCHITECTURE §18.6 и тесты редактора):
1. С инструментом рисования нажатие **всегда** создаёт новый объект — внутри и поверх других
   объектов, на месте ручек только что нарисованного. Клик без драга (< 4 px) у `R/E/A/L` объект не
   создаёт.
2. После создания инструмент **остаётся активным** (три стрелки подряд — без единой клавиши).
3. Новый объект **не выделяется**: ни рамки, ни ручек — ни во время рисования, ни после.
4. Смена цвета/размера/стиля **сразу после создания** (до следующего нажатия на холст, смены
   инструмента или `Esc`) меняет только что созданный объект **и** умолчание инструмента. Если есть
   выделение — меняет выделенные объекты и умолчание их типа. Иначе — только умолчание инструмента.
   Умолчания помнятся по инструментам между запусками.
5. Двигать и менять объекты — в «Выделении» (`V`) или **удерживая `Ctrl`** (временное выделение,
   отпустил — снова рисуешь). Курсор: у инструмента — перекрестие; с `Ctrl`/в «Выделении» над
   объектом — перемещение и обводка формы объекта.
6. Попадание по контурным фигурам, линиям и штрихам — **только по контуру** (допуск ≥ 6 px экрана);
   по залитым фигурам, тексту, счётчикам, плашкам «Скрыть» — по площади. Маленький прямоугольник
   внутри большого контурного выделяется кликом.
7. Выделенный объект показывает обводку формы и ручки; ручки рисуются **снаружи** мелкого объекта,
   чтобы не закрывать его. У штриха пера и маркера — подсветка самого штриха, без прямоугольной
   рамки и ручек (только перемещение).
8. Текст: `Enter` — новая строка; закончить ввод — клик вне, `Esc` или `Ctrl+Enter` (текст
   **сохраняется**); пустой текст удаляется. Клик инструментом «Текст» по существующему тексту —
   редактирование; двойной клик в «Выделении» — тоже. Угловые ручки — кегль, боковые — ширина блока.
9. Слои фиксированы снизу вверх: «Скрыть» → прожектор → маркер → фигуры, линии, перо, текст,
   картинки → счётчики. `Ctrl+]` / `Ctrl+[` (`+Shift` — на край) двигают объект внутри своего слоя.
10. `Alt`+драг и `Ctrl+D` — дубликат; стрелки — сдвиг 1 px (`Shift` — 10); `Shift` при перетаскивании —
    по одной оси; `Delete` — удалить выделенное; `Ctrl+A` — выделить все (переключает на `V`).
11. История: каждая завершённая операция — один шаг (создание, перемещение, ресайз, свойство,
    удаление, сеанс ввода текста); серии быстрее 500 мс (нудж, колесо) склеиваются. `Ctrl+Z` —
    отменить, `Ctrl+Shift+Z` / `Ctrl+Y` — вернуть; `Ctrl+Z` во время жеста отменяет жест.
12. Одиночные клавиши не работают во время ввода текста и IME; модификаторные сочетания — по
    `KeyboardEvent.code` (`Ctrl+Я` = `Ctrl+Z`).

**Свойства** — полоса под инструментами, только для активного инструмента / выделения: цвет
(8 пресетов + палитра + 3 последних; `Shift+1…8`), размер (5 ступеней; `1…5`, `[` / `]`), контур/заливка
(`F`), стиль (для стрелки, текста, «Скрыть»). Пресеты цветов: красный, оранжевый, жёлтый, зелёный,
синий, фиолетовый, чёрный, белый; по умолчанию — красный.

**Масштаб и панорама:** `Space` (держать) или средняя кнопка — панорама; `Ctrl+колесо`,
`Ctrl+=`/`Ctrl+-` — масштаб, `Ctrl+0` — вписать, `Ctrl+1` — 100 % (в окне редактора); `?` — шпаргалка
клавиш (и в оверлее).

### 9.4. Миниатюра после снимка (QAO)

Плавающая стопка миниатюр в нижнем углу монитора, где сделан снимок (левый — по умолчанию, правый —
настройка). Окно **не активируется** и не попадает в чужие записи экрана.

- До 4 карточек, новая снизу; пятая вытесняет самую старую.
- Автоскрытие через 10 с (5 / 10 / 30 / 60 с / никогда); наведение и перетаскивание ставят таймер на
  паузу; тонкая полоска показывает остаток.
- **Клик** по миниатюре — открыть в окне редактора. **Перетаскивание** — PNG-файл в любое приложение
  (после успешного переноса карточка закрывается).
- Кнопки при наведении: **Копировать** · **Редактировать** · **Закрепить** · **Сохранить** (если файл
  уже сохранён — «Показать в папке») · **Текст** (OCR → текст в буфер, с тостом) · **Удалить**
  (из истории; файл в папке не трогается) · **Закрыть** (×).
- Снимок, который не попал в историю (тип «Скриншоты» выключен или картинка больше 64 Мп), тоже
  получает карточку с превью, но только с кнопками **Копировать** · **Сохранить как…** · **Закрыть** —
  редактировать, закреплять и перетаскивать нечего: записи нет.
- Новый снимок прячет стопку на время оверлея и возвращает после; таймеры на это время стоят.
- Звук затвора при снимке (настройка; синтезированный короткий щелчок — без аудиофайла).

### 9.5. Окно редактора и закрепление

**Окно редактора** — обычное окно Windows (системный заголовок, как «Настройки»; есть на панели
задач и в Alt+Tab): заголовок «Имя — Liqlip», сверху инструменты и свойства, холст с масштабом и
панорамой (по умолчанию — вписать), справа сверху — **Копировать · Закрепить · Сохранить как… ·
Готово**. Открывается из QAO, из шелфа (`E` / меню «Редактировать» у картинок и снимков) и
настройкой «После снимка: открыть редактор».
- **Готово** (`Enter` в покое или `Ctrl+S`) — изменения сохраняются в ту же запись истории
  (неразрушающе: исходник и аннотации хранятся отдельно), картинка копируется в буфер (если
  «Копировать» вкл.), ранее сохранённый файл перезаписывается; окно закрывается. **Готово без
  изменений** запись не переписывает, но картинку копирует в буфер (если «Копировать» вкл.) и
  закрывает окно.
- **Закрепить** при несохранённых изменениях сначала сохраняет их в запись (как «Готово», окно
  остаётся открытым), затем закрепляет — закреплённое окно показывает то, что в редакторе.
  Копировать и «Сохранить как…» берут картинку как в редакторе сейчас и запись не меняют.
- Закрытие с несохранёнными изменениями — диалог «Сохранить / Не сохранять / Отмена».
- Одновременно открыто одно окно редактора; открытие другой картинки при несохранённых изменениях
  спрашивает то же.

**Закрепить на экране** (`Ctrl+P`, кнопки в оверлее, QAO, редакторе, меню шелфа) — картинка в
безрамочном окне поверх всех: драг — перемещение, колесо — масштаб, `Ctrl+колесо` — прозрачность,
двойной клик — 100 % ↔ исходный размер, `Esc` / × — закрыть; ПКМ — Копировать · Редактировать ·
Сохранить как… · Закрыть. До 6 закреплённых одновременно (седьмое закрывает самое старое).
Закреплённое окно следует за записью: после «Готово» в редакторе показывает новую картинку (тот
же масштаб), удалённая запись — плашка «Картинка недоступна».
Закреплённые окна **видны** в чужих записях экрана (их закрепляют как раз для показа).

### 9.6. Хранение и история

- Снимок — запись нового типа **`screenshot`** в той же ленте: карточка как у картинки + значок
  камеры в мета-строке; источник — приложение, активное в момент хоткея. Пилюля **«Скриншоты»**
  (после «Картинок»; снимки видны и в «Картинках»), токен `type:screenshot` (синоним `type:shot`).
- Тумблер типа «Скриншоты» в «Хранение → Какие типы сохранять»: выключен — снимки не попадают в
  историю (но копируются/сохраняются по настройкам).
- Ретенция, лимиты, избранное и папки работают как для остальных записей. Файл, сохранённый в
  папку, ретенция не трогает.
- **Аннотации неразрушающие:** у снимка хранятся исходник (без аннотаций) и документ аннотаций;
  картинка записи — сведённый результат. «Редактировать» открывает исходник с живыми объектами;
  «Готово» обновляет ту же запись (миниатюра, хэш, размеры). То же для любой картинки из истории:
  первое редактирование сохраняет её исходник.
- Меню действий шелфа (§3.7) для `image` и `screenshot`: **Редактировать** (`E`) · **Закрепить на
  экране** (`Ctrl+P`) · **Сохранить как…** · «Показать в папке» (если снимок сохранён в файл).
- Импорт из Liquid Tools переносит и снимки экрана (как `screenshot`, без аннотаций LT — они в LT
  запечены в картинку).
- Резервная копия `.liqlip` включает исходники и документы аннотаций.

### 9.7. Настройки → раздел «Скриншоты»

| Группа | Содержимое (по умолчанию) |
|---|---|
| **Захват** | Снимать сразу при отпускании (выкл.) · Лупа (вкл.) · Показывать размеры (вкл.) · Звук затвора (вкл.) · предупреждение про `PrtSc` и «Ножницы» (если включено в Windows) |
| **После снимка** | Копировать в буфер (вкл.) · Сохранять в папку (вкл.) — папка (`Изображения\Liqlip`, «Изменить…», «Открыть») и имя файла (`Liqlip {date} {time}`, плейсхолдеры `{date} {time} {app} {n}` с предпросмотром) · Формат PNG / JPG (качество 90) · Показать: миниатюру (QAO) / окно редактора / ничего · Угол миниатюр (левый / правый) · Скрывать миниатюры через (10 с) |
| **Редактор** | Сбросить умолчания инструментов · шпаргалка клавиш |

Хоткеи захвата — в разделе «Горячие клавиши» (группа «Скриншоты»). Онбординг получает шаг
«Скриншоты» (показ `PrtSc`, предупреждение про «Ножницы», если нужно).

### 9.8. Трей

Добавляются: «Снимок области» · «Снимок экрана» · «Снимок с задержкой ▸ 3 / 5 / 10 с» ·
«Скопировать текст с экрана» (с подписями сочетаний из настроек).

### 9.9. Состояния и ошибки

- Не удалось снять экран (ошибка GDI) — оверлей не открывается, HUD у курсора «Не удалось снять
  экран» + запись в лог.
- Сохранение в папку не удалось (нет доступа, папка удалена) — снимок всё равно в буфере и истории;
  тост в QAO «Не удалось сохранить · Изменить папку».
- OCR без языковых пакетов — кнопка «Текст» недоступна с подсказкой (как в шелфе, §3.12);
  «Скопировать текст с экрана» в этом случае оверлей не открывает — HUD у курсора «Для распознавания
  текста нужен языковой пакет Windows».
- Снимок больше 64 Мп — не в историю (лимит §2.3), но копируется и сохраняется.
