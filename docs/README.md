# Документация Liqlip — карта

Единый источник правды о **Liqlip**. Правило **doc-as-code**: меняется код — в том же
изменении правится профильный документ.

Маршрут новичка (человека или агента): [`../CLAUDE.md`](../CLAUDE.md) → [ROADMAP.md](ROADMAP.md)
§10/§11 → [SPEC.md](SPEC.md) → [ARCHITECTURE.md](ARCHITECTURE.md) → промпт своей задачи в
`prompts/` (агентам волн, локально).

| Документ | О чём |
|---|---|
| [SPEC.md](SPEC.md) | Продукт: поверхности, захват и приватность, шелф (вид, клавиатура, мышь, поиск, меню действий, просмотр, папки, сниппеты, очередь, OCR, состояния), настройки, трей, гарантии вставки, нефункциональные требования, рамки v1 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Стек, раскладка репо, окна, порядок `setup()`, схема SQLite, конвейеры захвата и вставки, стейт-машина шелфа, хоткеи, **IPC-контракт** (§9, уточнения W0 — §9.9), фронтенд, гейты и итог по `cargo test`, владение файлами, карта переноса из Liquid Tools, **межмодульные API** (§15) |
| [ROADMAP.md](ROADMAP.md) | Волны и статус (§10), открытые вопросы, журнал решений (§11) |
| `prompts/`, `progress/`, `review/` | Рабочие файлы координатора: dispatch-документы и промпты агентов, отчёты приёмки волн, ревью. Лежат локально и исключены из git (`.gitignore`) |
| [media/](media/) | Скриншоты для README: шелф, поиск, просмотр, меню действий, настройки — в тёмной и светлой темах, сняты с мок-адаптера |
| [picker.md](picker.md), [settings.md](settings.md) | Реверс-доки шелфа (вид, данные, клавиатура, примитивы слоёв для W2-C) и окна настроек/онбординга |
| [design-system.md](design-system.md) | Дизайн-система Liqlip (W2-E): токены, шкалы, правило концентричности, примитивы, состояния, отличия от Liquid Tools |
| [design-audit.md](design-audit.md) | Аудит интерфейса W1 → W2-E: дефект · правило · как исправлено |

Источник переноса — Liquid Tools (`../../liquid-tools-app/`, **только чтение**): его
`docs/library.md`, `docs/design-system.md`, `docs/hotkeys.md`, `docs/hotkey-engine-debugging.md`.

**Соглашения:** язык документации — русский; статус-маркеры ✅ 🟡 ⚠️ ⬜ ⏸️ ❌; ссылки на код —
кликабельные пути с номером строки; реверс-доки начинаются со строки «Замер: дата».
